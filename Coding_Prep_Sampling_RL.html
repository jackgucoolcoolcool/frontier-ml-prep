0 · The two helpers everything reuses

import numpy as np
rng = np.random.default_rng(0)                 # ONE generator, module scope — never inside a fn (#46)

def softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)    # stability: exp arg ≤ 0
    e = np.exp(z)
    return e / e.sum(axis=axis, keepdims=True)

def log_softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)
    return z - np.log(np.exp(z).sum(axis=axis, keepdims=True))   # never np.log(softmax(z)) (#7)

1 · The sampler (single most likely ask)

def sample(logits, temperature=1.0, top_k=None, top_p=None):
    # logits: (V,) raw scores at the last position
    logits = logits.astype(float).copy()           # we mutate; don't alias caller's array (#29)
    if temperature == 0:
        return int(logits.argmax())                # greedy shortcut, no div-by-0
    logits = logits / temperature                  # TRAP: on LOGITS, pre-softmax (#23)
    if top_k is not None:
        kth = np.sort(logits)[-top_k]              # np.sort is ASCENDING: [-k] = k-th largest (#27!)
        logits[logits < kth] = -np.inf             # TRAP: -inf, never 0 (#45)
    if top_p is not None:
        order = np.argsort(logits)[::-1]           # descending by prob
        p = softmax(logits[order])
        cum = np.cumsum(p)
        drop = cum - p > top_p                     # TRAP: keep the token that CROSSES p
        logits[order[drop]] = -np.inf              # (cum − p = mass strictly BEFORE each token)
    return int(rng.choice(len(logits), p=softmax(logits)))   # softmax renormalizes survivors
Say: temperature exponentiates (p1/τ renormalized) — dividing probs by τ is a no-op after renorm. Top-k masks with −inf because 0 is a mid-sized logit (e0=1 → rank-31k tokens leak). np.sort is ascending — [-k] not [k] (the kNN #27 trap). Top-p beats fixed k because the kept set adapts: peaked → few tokens, flat → many. RNG at module scope: a fresh default_rng(42) per call = identical completions (#46).

def generate(model, ids, max_new, cache):
    for _ in range(max_new):
        logits = model(ids[-1:], cache)            # only the LAST token; cache holds the rest
        ids = np.append(ids, sample(logits[-1], temperature=0.8, top_p=0.95))
    return ids
# equivalence test: cached greedy decode == full-context forward, token-for-token
# RoPE trap: pos = len(cache.K) read ONCE, same pos for q and k; append AFTER attending
# sliding window: K[-w:] keeps recent; K[:-w] keeps ANCIENT (the #66 inversion)

2 · Sequence log-prob (the glue every RL loss needs)

def sequence_logp(logits, ids, prompt_len):
    # logits: (T, V) for one sequence; ids: (T,) token ids
    logp = log_softmax(logits[:-1])                # position t predicts token t+1 (#33 shift)
    tok = logp[np.arange(len(ids) - 1), ids[1:]]   # (T-1,) fancy-index gather (Q91)
    mask = np.arange(len(tok)) >= prompt_len - 1   # response tokens only; prompt+pads out (#34)
    return (tok * mask).sum()                      # SUM — no length normalization
# batched: logp[np.arange(B)[:,None], np.arange(T-1)[None,:], ids[:,1:]] → (B, T-1)

3 · RLOO (your headline algorithm — pack 6.5)

def rloo_advantages(R):                            # R: (G,) terminal rewards of a group
    G = len(R)
    baseline = (R.sum() - R) / (G - 1)             # leave-one-out mean: excludes own reward
    return R - baseline

# training step (conceptual — the autograd part is one line in any framework):
#   adv = rloo_advantages(R)                       # constants w.r.t. θ (detached)
#   loss = -(adv * seq_logp).mean()                # seq_logp = Σ response-token logps per episode
Say: baseline is action-independent (built from the OTHER G−1 rollouts) → unbiased; variance drops without a critic. Sum, not mean, over tokens — length-normalizing re-weights episodes by 1/|τ|. Multi-turn: same loss, seq_logp = Σ over all turns' policy tokens, each scored against the context it saw, tool tokens masked (Q88) — RLOO has no per-turn credit to lose, so multi-turn IS single-turn. On-policy: the group must be sampled fresh from the current π, at the SAME temperature you score with.

4 · PPO clip · DPO · GAE (the follow-up trio)

def ppo_loss(logp, old_logp, adv, eps=0.2):
    ratio = np.exp(logp - old_logp)                # old_logp SAVED at rollout time — constant (#25)
    return -np.minimum(ratio * adv, np.clip(ratio, 1 - eps, 1 + eps) * adv).mean()
    # ratio = the off-policy correction for minibatch reuse; clip = trust region

def dpo_loss(pi_w, pi_l, ref_w, ref_l, beta=0.1):  # all: (B,) summed response logps
    margin = beta * ((pi_w - ref_w) - (pi_l - ref_l))
    return np.logaddexp(0, -margin).mean()         # -logsigmoid(m) = softplus(-m), stable (Q68)
    # 0.693 = ln2 = -log σ(0) → ref is aliased/re-synced to policy (#49, v2-23)
    # log BOTH pi_w and pi_l: margin can rise while both sink (v2-24)

def gae(r, V, dones, gamma=0.99, lam=0.95):        # V: (T+1,) includes bootstrap value
    adv, last = np.zeros(len(r)), 0.0
    for t in reversed(range(len(r))):              # 1. REVERSED — credit flows backwards
        nonterm = 1.0 - dones[t]                   # 2. dones gate BOTH terms (#47)
        delta = r[t] + gamma * V[t + 1] * nonterm - V[t]     # 3. V[t+1], not V[t] (v2-45)
        last = delta + gamma * lam * nonterm * last
        adv[t] = last
    return adv                                     # say: "reversed, dones gate both, V[t+1]"

4b · KL divergence — full-vocab exact + the three sampled estimators

def kl_divergence(p_logits, q_logits, axis=-1):
    # exact KL(p || q) per position — stay in LOG space end-to-end
    p_logp = log_softmax(p_logits, axis)
    q_logp = log_softmax(q_logits, axis)
    p = np.exp(p_logp)
    return np.where(p > 0, p * (p_logp - q_logp), 0.0).sum(axis)   # 0·(−∞) guard (v2-1)
    # (np.where still EVALUATES both branches → benign RuntimeWarning; the VALUE is right)

def kl_estimators(logp_pi, logp_ref):
    # per-token single-sample estimates of KL(π‖ref), tokens sampled from π
    logr = logp_ref - logp_pi              # log ratio, r = ref/π
    k1 = -logr                             # unbiased; individual samples CAN be negative — healthy!
    k2 = 0.5 * logr**2                     # low variance, biased
    k3 = np.exp(logr) - 1 - logr           # ≥ 0 pointwise AND low-bias — the RLHF standard
    return k1, k2, k3
Say: $\;$KL(p‖q) = Σ p·(log p − log q) ≥ 0, and it's asymmetric — in RLHF we penalize KL(π‖ref): expectation under π, so it punishes π putting mass where ref doesn't. Use the exact form when you have full logits (one row per position — cheap); use sampled estimators when you only have chosen-token logps. Never clamp k1 at 0 — nonnegativity is a property of the expectation, not of samples; clamping biases the meter while the policy drifts (v2-50). k3 is nonnegative by construction, so nobody is tempted to clamp — that's why stacks use it. Torch trap: F.kl_div(input, target) wants input = log-probs and reduction='batchmean' (v2-3) — probs in, garbage out, possibly negative. Free assert: KL(p‖p) must be exactly 0.

5 · On/off-policy — the 30-second frame if he goes conceptual

"On-policy-ness is about whose distribution the expectation is under. REINFORCE/RLOO/GRPO: expectation under current π → fresh samples, discard after one step. PPO: deliberately slightly off — the ratio IS the importance correction for reusing one batch over epochs, clip bounds the stretch. DQN/SAC: truly off — a bootstrapped critic can evaluate anyone's transitions; impractical at token level. DPO: fully offline — the KL-constrained objective solved in closed form. And the quiet trap: rollout temperature ≠ 1 makes 'on-policy' silently off-policy — the behavior policy is the tempered one; sample training data at τ=1 or importance-correct."
