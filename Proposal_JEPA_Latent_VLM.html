LatentFusion: Multimodal Language Models that Predict in Frozen Self-Supervised Latent Spaces

Research Proposal · July 2026 · draft v0.3
see in CLIP space predict in DINO/JEPA space frozen targets — no collapse no pixel-generative cost

Abstract

Current unified multimodal models couple language modeling with pixel-level generative objectives — discrete VQ tokens (Chameleon) or diffusion over image latents (Transfusion). Both spend capacity on high-frequency detail irrelevant for reasoning, and neither exploits the strong predictive representations learned by self-supervised vision models. LatentFusion is a language model that consumes images through a standard text-aligned vision tower (CLIP/CoCa) but is trained to predict upcoming visual content in frozen self-supervised latent spaces — DINOv2 for image spans (dense semantics, geometry) and video-JEPA for video spans (dynamics, physics). Input and target spaces are deliberately decoupled: the model sees in a text-aligned space and predicts in spaces encoding exactly what text alignment lacks. Targets are frozen and precomputed, so collapse is impossible by construction. We study a spectrum of objectives — dense regression, InfoNCE, discretized-latent cross-entropy (including an extended-vocabulary variant that is literally standard LLM training), and a latent flow head — as progressively stronger treatments of regression-to-the-mean. Hypothesis: stronger spatial, temporal, and world-model capability per FLOP than pixel-generative training, trading away native synthesis (recoverable via a separately trained decoder).

One-line pitch: a language model that sees in CLIP space and learns to predict in DINO/JEPA space acquires the dense-spatial and temporal world knowledge that text-aligned VLMs structurally lack — without pixel-level generative cost.

1. Motivation

  1. Pixel objectives overpay for detail. JEPA-family results (I-JEPA, V-JEPA, V-JEPA 2) show latent-space prediction yields better representations at a fraction of the compute — but with no language interface.
  2. Text-aligned encoders are blind to what SSL encoders see. CLIP/CoCa features carry little dense spatial structure (DINOv2: parts, layout, geometry) or motion/physics (V-JEPA). Predicting in those spaces injects exactly the missing information — while the input tower keeps OCR/VQA/grounding intact.
  3. Frozen targets remove JEPA's hardest engineering problem. No EMA targets or stop-gradients: precomputed frozen targets make training a stationary-target problem — collapse is impossible.
The input space supplies what the model reads; the target spaces supply what it must learn to anticipate.

2. Related work (positioning)

Three converging threads: (i) feature prediction as a VLM auxiliary objective (MetaMorph, ROSS, Emu/Emu2; REPA in the mirror direction); (ii) world models in frozen SSL spaces — without language (DINO-WM, V-JEPA 2-AC, IWM); (iii) semantic visual tokenizers (SEED, LaViT, VILA-U; Janus's decoupled encoders).

3. Method

3.1 Architecture: decoupled input and target spaces

Input and target streams never mix; target encoders never run in the training loop.

Design principle — complementarity: predicting SigLIP targets from a CLIP input is nearly redundant; predicting DINO/JEPA targets injects what the input space lacks. Separate heads per target space (different dims/statistics — never mix them in one head).

3.2 What to predict: future, not same-frame

Main design risk, handled up front: predicting the latents of the same frame the tower is encoding degenerates into CLIP→DINO feature translation — distillation, not world modeling. Targets are the latents of upcoming content: the next image in the interleaved sequence, or frames \(t+k\) given frames \(\le t\). Same-frame translation is kept only as a small auxiliary term, with a translation-only control run for comparison.

3.3 The loss, concretely, in a standard causal LM

Everything stays next-token prediction under the ordinary causal mask; only what the head outputs changes at positions whose next slot is visual:

\[ \mathcal{L} = \underbrace{\sum_{i:\,x_{i+1}\in\text{text}} -\log p_W(x_{i+1}\mid h_i)}_{\text{unchanged text CE}} \;+\; \lambda \underbrace{\sum_{i:\,x_{i+1}\in\text{visual}} \ell\big(g(h_i),\, \bar z_{i+1}\big)}_{\text{latent prediction}}, \qquad \bar z = \text{whiten}(z) \]
Blue = unchanged text CE. Teal = latent loss ℓ ∈ {L2, InfoNCE, discrete-CE, flow}. v-slots are CLIP-tower embeddings; z̄ are whitened frozen targets.
# drop-in on any HF-style causal LM — causal mask untouched
h = model.transformer(inputs_embeds=emb).last_hidden_state    # [B, L, D]

# text loss — unchanged
L_text = F.cross_entropy(lm_head(h[:, :-1]).transpose(1, 2), tokens[:, 1:],
                         reduction='none')[text_next_mask[:, 1:]].mean()

# latent loss — positions whose NEXT slot is a visual target
pred  = dino_head(h[:, :-1][visual_next_mask[:, 1:]])          # [M, d_dino]
tgt   = (z_dino - mu) / sigma                                  # precomputed, whitened, frozen
L_reg = F.mse_loss(pred, tgt)                                  # or InfoNCE / discrete-CE / flow

loss = L_text + lam * L_reg

Input embeddings for visual slots come from the CLIP/CoCa tower through a projector; targets z ship from the dataloader like labels. For future prediction the target at an image span is the next span's latents — same code, different alignment.

3.4 Prediction objectives (ablation axis)

(a) Dense regression

\[ \mathcal{L}_{\text{reg}} = \tfrac{1}{N}\sum_i \|\hat z_i - z_i\|_2^2 \]

Simplest; dense gradient (MetaMorph: improves understanding); collapses multimodal futures to their mean. Optional VICReg-style variance regularizer.

(b) Contrastive (InfoNCE)

\[ \mathcal{L}_{\text{nce}} = -\log \tfrac{\exp(\mathrm{sim}(\hat z_i, z_i)/\tau)}{\sum_j \exp(\mathrm{sim}(\hat z_i, z_j)/\tau)} \]

Rank the true future above in-batch negatives — no mean-collapse, negligible cost, most JEPA-native (energy-based) fix.

(c / c′) Discretized-latent cross-entropy

Quantize the frozen target space once (k-means / FSQ); predict codes with softmax CE — a categorical natively represents multimodal futures. (c′): add the codes to the LLM vocabulary and predict through the normal LM head — the whole system is literally standard LLM training: one loss, perplexity + scaling curves for free. Caveat: codes must quantize semantic spaces (DINO/JEPA, SEED/LaViT-style) — pixel-VQ codes would smuggle texture back in and revert to Chameleon.

(d) Latent flow-matching head (MAR-style)

\[ \mathcal{L}_{\text{flow}} = \mathbb{E}_{t,\epsilon}\|v_\theta(z_i^t, t, c_i) - (z_i - \epsilon)\|_2^2 \]

LLM emits conditioning \(c_i\); small MLP models the full continuous conditional. Sampleable rollouts; iterative inference (cheap: low-dim); needs schedules + whitening. Upper-bound treatment.

3.5 Optional: latent-to-pixel decoder

A diffusion decoder trained separately to invert the target encoders (RCG-style), for visualization/generation only; out of the main loop by design.

4. Hypotheses & experiments

H1 — Understanding

Latent prediction on frozen SSL targets improves an otherwise-identical baseline: spatial suites for DINO targets; temporal/physical suites (Perception Test, TempCompass) for JEPA targets. Input tower is CLIP/CoCa, so OCR/DocVQA should be unchanged — a regression test, not a trade-off.

H2 — Target space matters (headline)

Swap targets among SigLIP / DINOv2 / V-JEPA, all else fixed. Prediction: SigLIP ≈ no gain (redundant with input); DINOv2 wins spatial; V-JEPA wins temporal/embodied. The per-benchmark-family map is publishable on its own.

H3 — Objective

(b)/(c)/(d) ≥ (a) wherever futures are genuinely multimodal (video continuation, next-image-in-document); (a) stays competitive for understanding. Latent rollout metrics (feature PSNR, retrieval@k), planning success à la V-JEPA 2-AC / DINO-WM.

H4 — Efficiency

At matched FLOPs, better spatial+temporal scaling than a Transfusion-style pixel-diffusion baseline (0.3B/1B/3B ladder; objective (c′) gives the cleanest scaling ordinate).

De-risking probe (week 1): linear-probe frozen DINOv2 + V-JEPA 2 features on all target evals before Stage-2 training; weak probes ⇒ revise target spaces first.

Minimal viable experiment: existing CLIP/CoCa tower + open 7B LLM + frozen DINOv2 targets, objectives (a) + (c′), interleaved image-text data, targets precomputed. Baseline: same run, prediction loss off. Video/JEPA arm second.

6. What this is not

  • Not an image generator. Native synthesis is deliberately traded away; §3.5 recovers it approximately if needed.
  • Not joint JEPA training. No EMA/stop-grad anywhere; stability bought with frozen targets, at the cost of non-adaptable target spaces (probed in week 1, mapped in H2).
